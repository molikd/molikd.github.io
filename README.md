# david.molik.co

The personal and research website of [David C. Molik](https://david.molik.co/), associate professor and department head of the Open Publishing Exchange at Kansas State University Libraries.

The site is a lightweight, accessible static website published through GitHub Pages. Scholarly works are maintained authoritatively in [ORCID](https://orcid.org/0000-0003-3192-6538); institutional information is maintained in [K-State Experts](https://experts.ksu.edu/david.molik).

## Local preview

Serve the repository root with any static web server, for example:

```sh
python3 -m http.server 4000
```

Then open `http://localhost:4000`.
